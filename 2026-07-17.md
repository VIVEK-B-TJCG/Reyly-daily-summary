## Topics Discussed

### 1. FCC Data Integration — Functionally Complete but ⚠️ Data Quality Issue
- Integration works
- **Problem:** FCC data is **6 months outdated** → some active providers appear unavailable at valid zip codes
- **Mitigation:** double-verification when redirecting users to provider websites

### 2. Provider Recommendation Strategy — Full Address Required
- **Baseline:** 5 nationwide fixed wireless providers (AT&T Air, T-Mobile 5G, Verizon 5G, Mint Internet, Visible Internet) surface via zip code
- **Then:** collect **full address at "Start My Savings"** step to verify plan-level availability (varies by household)
- **"Improve My Savings" hook** proposed to prompt address entry

### 3. 🐛 Switch Kit — Provider Tile Click = No Action Bug
- User feedback: clicking provider tiles (e.g., Verizon) in Switch Kit did nothing
- **Fix:** clicking a tile navigates directly to Switch Kit with that **provider pre-loaded** + allows line count input

### 4. Regional Cable Provider Filtering 🎯
- **Insight (Romeo):** 4 cable cos (Xfinity/Spectrum/Cox/Optimum) are **regional monopolies with zero overlap** — never present in same market
- **Decision:** filter out the **3 non-applicable** cable providers per user zip code — show only the 1 valid option
- Improves recommendation accuracy

### 5. Customer Acquisition Cost — Joey Jablonsky Article
- Mark shared article on CAC
- Discussion: **human interaction = differentiator** but also raises cost
- Trade-off unresolved — noted for future strategy

### 6. Landing Page Redesign — "Chase-like" Aesthetic 🎨
- **Direction:** move away from "robotic" look → **professional, trusted financial** feel
- **Away from teal palette**
- **Carousel feature** replaces static text for value propositions:
  - Wireless savings
  - Internet savings
  - (Cycle through promotional messages)

### 7. Billing Account — Free Trial Expired 🐛
- Blocked access to billing settings
- **Resolved:** upgraded project account plan → billing access restored
