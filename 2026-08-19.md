## Topics Discussed

### 1. 🔄 Bundle DB Structure — REVERSAL of Aug 17 Approach
- **Aug 17 locked: separate mapping spreadsheet (~20 entries)**
- **Aug 19 REVERSES: integrate bundle fields directly into existing mobile + internet sheets** — no separate third document
- Jayesh's proposal: add 2-3 bundle-tracking fields to the existing sheets; DB has broadband table + mobile table already; adding a third mapping table = extra maintenance surface
- Alan not tied to the mapping approach — his spreadsheet was "first pass to see what's needed"
- 🎯 **DECISION: Jayesh updates mobile + internet sheets w/ additional bundle fields; Alan populates viable combinations**

### 2. 🎯 Scope Restricted — A, B, D Discount Types Only
- Alan's spreadsheet supported many discount permutations
- 🎯 **DECISION: Only A (mobile discount), B (broadband discount), D (free line / free equipment) — drop the rest for initial rollout**
- If empty bundle_type → no bundle for that combo (no need to fill K/L/M columns)
- Additional types can be added post-rollout based on user feedback

### 3. 🎯 Bundle Availability = Copy, NOT Math (in current tool version)
- Extensive debate on how to compute discount value across permutations
- Xfinity example: free mobile line valued at $30/mo ONLY if internet ≥ 300 Mbps
- If customer picks 4 GB mobile plan → no discount; if picks $45 plan → still gets $30 credit, pays $15 extra
- Adds significant complexity — customer picks ≠ what they're on
- 🎯 **DECISION: Indicate bundle AVAILABILITY via copy ("There's a bundle available — click here")**, not a computed dollar discount in v1
- Down the road: could compute exact math once user confirms plan; for now: surface existence, not value

### 4. 🐛 UI Confusion — "Current" vs "Recommended" Plan
- Follows Aug 17's Steuart case — user misread "current $50" as recommendation, was actually paying $65
- Romeo: **"Recommended plan" needs to be MORE PROMINENT** — currently lost in layout
- Suggested copy: "best plan for your setup" / "best value" / "really suggested" — beat the user over the head
- Jayesh: already added "update your details" copy for accuracy corrections (from Aug 17 action)

- Copy updates (hassle-free wording) done
