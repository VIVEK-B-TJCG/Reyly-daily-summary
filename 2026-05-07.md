## Topics Discussed

### 1. Flex Offer = Monetization Tool, NOT Source of Truth ✅
- **Key clarification:** Flex Offer platform does NOT provide detailed plan information
- Flex Offer primarily displays **promotions and product advertisements**
- **Consequence:** Reyly's internal database remains the **primary source of truth**
- Flex Offer purpose narrowed to:
  - Generating deep links
  - Tracking
  - Managing commissions
- Flex Offer is structured more like an **e-commerce site focused on offers** — not a plans database

### 2. Monetization & Deep Linking Strategy
**The flow:**
1. Use **internal database** to select best plan for user (e.g., suggest Mint Mobile $50 plan)
2. Take that plan's **direct link** from internal DB
3. Send link to Flex Offer to **generate a deep link** (containing affiliate code + ID)
4. Use the generated deep link to redirect the customer
5. Flex Offer tracks the transaction → commissions secured upon purchase

### 3. Mark's Clarification Request
- Mark asked for visual map of the process
- Expressed uncertainty about how this ensures value for the customer
- Martin: not surprised Flex Offer lacked detailed data

### 4. Flex Offer Data Available (Limited)
- Only provides:
  - Promotion titles
  - Run dates
  - Descriptions
- **NO detailed plan attributes** that could feed the database
- Flex Offer offers **two feeds:**
  1. Promotional data feed
  2. Product data feed (devices)

### 5. Deep Link Generation — Technical Steps
- Take specific plan link from Reyly database
- Pass to Flex Offer with required **5 IDs** + traffic source info via their API
- Hit "Generate" → deep link created
- Used for commission tracking when user purchases
- Mark: "makes sense" but preferred to see it in action before further comment

### 6. DIY Kit Final Testing
- Jayesh finished other tasks
- Conducting **final testing** of DIY kit
- Ensuring DIY kit shows proper customer data
- Starting implementation of Flex Offer redirection for commission tracking

### 7. Outstanding Email — Jayesh's Yesterday Note
- Martin acknowledged receipt of Jayesh's email from previous day
- Hadn't reviewed yet → committed to read this afternoon
- Mark + Martin to meet at **11:00 AM** to discuss email questions
- **Response to Jayesh expected by noon today**
