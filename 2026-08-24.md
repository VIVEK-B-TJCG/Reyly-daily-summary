## Topics Discussed

### 1. 🎯 Zip Code Collection — Front-Load into First Page
- **New flow:** collect zip code on the **first page** → filter FCC providers → show only relevant options
- Prevents showing users providers not available in their area (Visible not in their zip, etc.)
- **UI:** dynamic **slide transition** on the same page (no page load between zip → provider selection) — Romeo: "Oh, that's cool, Jayesh"
- Reuses existing form position — no new page needed

### 2. 🎯 Free-Trial Paywall — DEFER to "Guided Switch"
- **Original plan (Aug 21):** show hassle-free only, gate maximum savings behind free trial + CC upfront
- **New concern (Romeo):** high abandonment rate if CC required too early
- **NEW DECISION:** Show **maximum savings for FREE** (no CC) → gate ONLY at the **"Guided Switch" step**
- Rationale: users need to see the value ($1,500 savings, etc.) BEFORE being asked for CC
- Users get an **"escape hatch"** — direct link to Mint (or provider) without paying → Reyly still gets Flex Offers affiliate revenue
- Mark: "we're at the five-yard line" — this is the make-or-break friction test

### 3. 🎯 Savings UI — Show Current + Membership Amounts
- **Old:** UI showed maximum savings (Aug 21 direction) — but user was already at that view without paying
- **New:** show **BOTH amounts side-by-side**:
  - "Without membership, your current saving is **$2,600/yr**"
  - "With Reyly membership, max saving = **$5,400/yr**"
  - CTA: "Unlock maximum savings — start 30-day free trial"
- Same pattern inside per-provider cards (AT&T card shows current + max)

### 4. 🎯 Subscription Page Layout
- **Popular streaming services at TOP** (Netflix, Hulu, YouTube, etc.)
- **Browse all** option below
- **CTA at bottom:** "Upgrade to Premium" — clarifies these are subscription setup, not notification setup
- **Typo caught by Mark:** "upgrade" spelling in Figma

### 5. 🎯 Device Information Screen — REMOVED
- **Killed screen:** the one asking for physical SIM number + IMEI (32-digit inputs)
- **Reason (Romeo):** unnecessary friction — carrier will ask for this later anyway
- Screen removed from user flow entirely

### 6. 🎯 Transfer PIN — MASSIVE Simplification
- **Old complex guide (Romeo owns the blame):** step-by-step multi-provider walkthrough with 5+ options
- **New — 2 options only:**
  1. **Default: dial code + handset visual**
     - AT&T: `*7678`
     - Verizon: `#7678`
     - T-Mobile: `#7678#`
     - Other carriers: "call customer care" + number
  2. **Backup: app + visual walkthrough** for top 3 providers only
- **Keep complex version** in internal library/knowledge base (not user-facing)
- Mark: takes friction out by not going number-by-number

### 7. ✅ Database — Bundle + Multi-Month Ready
- Database updated to manage:
  - Plan terms + monthly pricing
  - **Bundle discounts** (flat + percentage type)
  - **3 / 6 / 12 month contracts** (multi-column)
  - Provider dropdown connections (mobile ↔ internet sheets linked)
- **500 fields ready to populate**
- Jayesh needs to walk Romeo through **a couple of test cases** BEFORE full population (e.g., "Xfinity + T-Mobile" → what does the UI show?)

### 8. 🎯 App Copy — SIMPLIFY (Not Website-Length)
- **Current:** app copy mirrors website — too wordy
- **New pattern:** high-level only
  - "Save up to $X on Wireless"
  - "Save up to $X on Internet"
  - "Save up to $X on TV & Streaming"
- Short, scannable — not descriptive sentences
