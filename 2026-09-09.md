## Attendees

## Topics Discussed

### 1. 📦 Bundle Interface — LIVE + polish
- Jayesh demoed live Pay-As-You-Go wireless bundle w/ tiered savings by contract duration
- Romeo: remove redundant "new bill" text + "get plan details" links
- Add "Show me another option" button next to Save-with-Current-Provider

### 2. 📦 Bundle Suppression Threshold — 🎯 ~$200/yr
- **Suppress bundle recommendation UNLESS non-bundle savings/yr are ≥ ~$200 MORE than the bundle**
- Rationale: keep users on best absolute savings unless bundle is materially better

### 3. 📦 Same-Provider Bundle Logic (edge case)
- Scenario: user has Spectrum internet + Spectrum wireless
- System should suggest bundle that **adjusts current plan** (e.g., $40 → $30) to unlock savings without switching providers

### 4. 🔄 Internet Usage Categorization — SIMPLIFIED to BINARY
- Initial proposal: **3 buckets** — simple email / single stream + Zoom / multi-stream + gaming
- Final: **BINARY — Typical vs. High-End** (simpler maintenance, less UX friction)
- Jayesh to update DB with binary internet usage field

### 5. 🎯 Gaming Assumption — 1 Gbps baseline
- Current system estimates mid-tier price — inaccurate for power users
- Fix: **if user self-IDs as gamer/heavy → predict 1 Gbps plan** (not 100 Mbps mid-tier) so savings stay realistic
- Alan: if cost RISES for heavy users → pivot copy from "savings" to **"better quality service"**

### 6. 🚫 Fixed-Wireless Access SUPPRESSED for Gamers
- Fixed wireless (T-Mob 5G Home etc.) insufficient bandwidth for heavy gaming
- Mark: display explanatory message ("cheaper plan not shown because your usage requires premium connection")

### 7. 🔄 Xfinity Mid-Tier Recategorized: 1 Gbps → 500 Mbps
- 500 Mbps sufficient for standard streaming + web conferencing
- 1 Gbps reserved for gaming/high-bandwidth

### 8. 🌎 PR Providers — Regional Mid-Tier
- Puerto Rico providers (Liberty etc.) need region-specific mid-tier pricing
- Group by region: US vs. non-US; some providers (T-Mob) don't need mid-tier distinction

### 9. ✅ Membership Flow — $29.99 confirmed live
- Switch Pass membership functional at $29.99/yr

### 10. 🚀 Android Developer Verification — in progress
- Domain + mobile-number verification via DNS records
- New owner account created; Alan to share credentials; coordinate DNS with Jayesh
