- New copy: "Save up to $X/year"
- Same fix for the $1,440 and comparable figures throughout

### 4. 🎯 TV/Streaming Display Logic — SHOW ALL 4
- **Rule:** if user reports spending on cable (e.g. $45), show **all 4 viable services** if they have viable options
  - Prevents users thinking a provider was overlooked
  - Reconsider when catalog grows beyond ~4-5
- **No cheaper alternative available?** → "You already have a great deal. Check back for future offers."
- **PLUS:** offer to set up **streaming reminders** (Cancel / Pause / Downgrade actions)
- Romeo: "Send them to do something other than 'you're done' — set up your streaming reminders"
- Alan: "Our whole goal is to save them money, not to upsell existing platforms"

### 5. 🎯 TV/Streaming Routing Logic — CONFIRMED
- **Basic viewing needs** → basic option
- **Single niche interest** → niche-specific provider (Sling, etc.)
- **2+ niches** (sports + family + news) → premier sets (Fubo, YouTube TV, etc.)
- Question set (movies / TV / live TV / sports) — locked in

### 6. 🎯 Ideal Customer Profile — Explicit Confirmation
- $720 upfront (12-mo Mint) → **aligns with our ICP**
- **NOT our target:** fresh-out-of-school millennials where "every dollar is precious"
- Romeo confirmed his own family: 2 lines × $180 upfront + ~$100 taxes = $600 for 3 lines, no bill for a year
- Alan: "For our ICP, $720 today is very manageable"
