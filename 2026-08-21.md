## Topics Discussed

### 1. 💰 🎯 PRICING OVERHAUL — Full Model Locked (Reverses Aug 14)
- **Aug 14 locked: $24.99 DIY + $25/yr White Glove**
- **Aug 21 REVERSES + expands to a full "either/or" pricing model:**

| Tier | Web | App Stores (Apple/Android) |
|------|-----|----------------------------|
| **Yearly subscription** | $19.99/yr | $24.99/yr |
| **À la carte per-line switch** | $9.99 / line | $9.99 / line |
| **Family cap (up to 4 lines)** | $25.00 | $25.00 |
| **5th+ line (over cap)** | $9.99 per additional | $9.99 per additional |

- Web price avoids Apple/Google 30% commission
- "Ask forgiveness, not permission" if Apple flags web vs. app differential
- Yearly = notification + tracking features; à la carte = switching only, no notifications
- 🎯 **DECISION: Either/or model** — user either pays yearly OR one-time à la carte per line

### 2. 🎯 30-Day Free Trial — New Onboarding Gate
- **Free trial: 30 days, notification services ONLY**
- To perform an actual carrier switch → user MUST upgrade to full yearly subscription
- Activating switching triggers the paid year
- ARR strategy: if user pays to switch, first year of notifications is bundled free → locks year-2 renewal
- 🎯 **DECISION: 30-day free trial for notifications; paywall + CC entry required to view personalized savings on savings page**

### 3. 🎯 Tiered Savings Presentation — Two Paths
- **"Save with current carrier"** — visible without trial (base savings on current plan)
- **"Save by switching (maximum savings)"** — requires 30-day trial start (CC entry) to unlock
- Design intent: show potential higher savings behind trial → drives trial activation
- Jayesh to design layout

### 4. 🎯 Concierge Support Logic
- Concierge = scheduled call service ($15/call cost)
- **Placement: only surfaces at the 95% journey mark for SUBSCRIBED users** — never on à la carte
- Explicitly NOT surfaced as an 800# on landing pages
- Fallback path: knowledge base → robot relay → concierge (last resort)
- Free trial period counts as "subscribed" for concierge access (transitions to paid)
- Concierge calls capped per subscription year to control cost

### 5. 🌐 Zip Code Entry — Fixes Travel Case
- Alan: users traveling outside home market can't access home broadband options (geolocated ≠ actual)
- 🎯 **DECISION: Add zip-code input field on landing page** — user specifies location manually
- Displaces reliance on IP-based geolocation for provider surfacing

### 6. 📺 Cable Replacement Flow — Copy Logic Corrected
- Current copy was reversed (user selects "no cable" → still shows cable-downgrade options)
- 🎯 **NEW LOGIC:**
  - "Do you subscribe to cable/satellite?" → **NO** → streaming reminders (no downgrade options)
  - **YES** → "hassle-free" path: monthly spend input + content prefs (sports/news/family) → premium streaming recommendations w/ clear value prop
- Free to use; affiliate links under providers future roadmap

### 7. 🎯 Popular Subscription Icons — Navigation UX
- Add high-traffic icons (Netflix, Hulu, etc.) at TOP of subscriptions page
- Prevents scroll-to-bottom pain point
- Jayesh action

### 8. 🎯 Monetization — Tag EVERY Click
- Every user interaction — even pre-subscription — tagged through affiliate networks (Flex Offers / Impact)
- Long-term revenue play: even non-converters generate referral commission

### 9. 🎯 Switching Flow — Trial + Help Me Switch
- User already on 30-day trial + clicks "Help me switch" → choice:
  - End trial → activate full annual membership (pay $19.99–$24.99/yr)
  - OR pay per-line fee ($9.99/line)

### 10. 📱 App Store Submission Pipeline
