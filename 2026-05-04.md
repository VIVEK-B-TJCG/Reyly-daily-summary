## Topics Discussed

### 1. Admin Panel Demo — Wireless Plan Management
- Jayesh demonstrated admin panel for wireless plans + providers
- Capabilities:
  - **Upload CSV / Excel** of plans
  - **Download sample file** template
  - **Edit existing plan details** (e.g., change price from 6 → 30)
  - All plans visible and editable

### 2. Wireless Plan Database Fields
- Captures: country, prepaid/postpaid designation, plan name, GB limits, plan type
- **Mid-tier setting:** can select which plan (e.g., 4GB, 2.0 extra, 2.0 premium) becomes the **mid-tier** for a provider
- Mid-tier selected on backend = the one **surfaced on the platform** (per Apr 13 logic)

### 3. Advanced Fields from Excel
- After Excel upload, editable fields include:
  - Activation fees
  - Regular fees
  - Surcharges

### 4. Internet & Streaming Plan Management
- Same management logic applies to **internet plans**
  - Plan name, type (e.g., fixed wireless), configuration, pricing
- **Streaming:** plan info from back end; details uploaded from source Excel

### 5. Engine Settings Configuration ✅
- Configurable core logic:
  - **Slider range:** 50 → 400, $10 steps (fully changeable)
  - **Insurance adjustment:** e.g., $50 per insurance
  - **Max lines before lead form** (e.g., 6+ triggers form)
  - **Engine results filter:** prepaid / postpaid / both

### 6. DIY Guides — Dynamic Provider Steps
- Admin panel includes dynamic interface for "Do It Yourself" guides
- Example: Spectrum DIY guide for changing a plan
- Manageable from back end:
  - Steps for changing a plan
  - Steps for finding account number
  - Steps for finding transfer PIN
- Confirmed: all DIY kit steps **dynamic** — can be updated to reflect provider changes

### 7. Front-End Plan Results — Example
- **Example user:** 3 lines on AT&T mid-tier
- Hassle-free suggestion: switch to **value 2.0 plan**
- Total savings: **$540/year**
- Step-by-step plan change instructions provided

### 8. Maximum Savings Logic — Cheapest Unlimited
- Maximum savings path suggests **cheapest available unlimited plan** (currently Mint Mobile)
- **Edge case raised:** what if user is already on a cheap plan like Mint Mobile?
  - Hassle-free is already the maximum saving
  - Should the maximum saving option still surface?
- **Mark's resolution:** if max savings achieved via hassle-free → don't surface max saving option, OR show message if clicked
- _(this is the seed for the May 6 "Improve Savings" removal decision)_

### 9. Front-End Switch Kit Flow
- User flow:
  - Input mobile number
  - Find account number
  - Find transfer PIN
- **Paywall placement:** before PIN number entry (per Apr 1 decision)
- Pro members bypass paywall

### 10. Reminder Functionality
- Quick-pick options: today, tomorrow, next week
- Custom date picker available
- Events: plan cancellation or upgrade
- Email notification delivered
- **Storage location:** team agreed reminders + savings ledger should live in the **wallet** (current and past visible)

### 11. "Better Coverage" Logic ✅
- Logic confirmed: avoid customer's current primary carrier
- Reason: request for better coverage suggests dissatisfaction with current service
- _(consistent with Apr 23 decision)_

### 12. "Cheaper Plan" Option — Redundant
- Discussion: "Cheaper Plan" option is **redundant** because engine already surfaces cheapest plans with current GB minimums
- Briefly considered: binary option where user must choose **better coverage OR cheaper plan**
- _(this concern carries forward to May 5 blocker → May 6 removal)_

### 13. Spanish Translation Requirement
- Martin to add Spanish copy for front-end
- **Deadline:** complete Spanish translation by **May 15**

### 14. UI Text Adjustments
- **"Save up to"** → change to lowercase **"save"**; **remove "up to"** phrase

### 15. Development Strategy / Next Steps
- Martin: logic issues expected → work through them now that flow is built
- Jayesh will prioritize **moving dev server build → staging server** for team testing
- Team will create list of needed logic adjustments while testing
- **Mark's suggestion:** consider bringing in a **program manager** to maintain focus on commitments
