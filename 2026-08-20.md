# 2026-08-20 — Reyly Team Meeting (Thursday, T+52 Post-Launch)

## Attendees
- Mark Gilmor, Romeo Reyes, Jayesh Gohel, Alan Zall

## Topics Discussed

### 1. 📦 Switch Kit — "Fast Track vs. Guided" UX Question
- Jayesh proposes: users who already know their target provider (e.g., "my relative loves Mint, I want Mint") should bypass the recommendation wizard
- Current wizard = valuable "speed bump" (saves time, builds confidence) but also drops off users who arrive with a decision made
- Path names debated: Fast Track / Help Me Switch / Guided Switching / Switch Guidance
- Mark: don't make guidance secondary — it's the value prop; make "go direct to deal" the alternative
- 🎯 **DECISION: Feature SHELVED to V3 backlog** — don't complicate wizard mid-development; revisit post-bundle rollout

### 2. 🔄 Screenshot Upload — EXCLUDED (Reverses Jul 21 Plan)
- Jul 21 planned: OCR-based screenshot upload for account# / PIN / IMEI
- Jayesh confirmed capability exists (OCR works across all providers)
- Alan flagged friction: on desktop, screenshot must be phone → self-email → upload → step
- 🎯 **DECISION: Do NOT implement screenshot upload for Switch Kit** — maintain the original in-flow wizard experience
- Rationale: adds complexity, extra step, user education burden — not worth it for v1

### 3. 🎨 Figma Journey Maps — New Requirement
- Alan asked for a visual flow map of all user paths through the platform (to see where paywall lives, where drop-off happens)
- Especially critical since the Fast Track question exposed how many possible paths exist
- 🎯 **DECISION: Jayesh generates Figma flow maps for every user journey path**
- Enables: paywall-placement analysis, PostHog metrics correlation (where do users exit?), business-model decisions

### 4. 💰 Paywall Placement Concern — Model Impact
- Current paywall = pre-transfer-PIN step in Switch Kit (subscription gate before guidance)
- If we add "go direct to Mint" → skip Switch Kit → no paywall opportunity → rely purely on Flex Offers affiliate commission
- Not every provider has a Flex Offers link (Xfinity, Spectrum → likely Impact or other networks)
- Mark: "this is a significant switch move — need to map it before slapping it together"
- Jayesh: user going straight to Mint = 0 subscription revenue (only affiliate if link tagged)

### 5. 🎯 New Workflow Process — Consensus Before Dev
- Mark expressed concern: every mid-development pivot delays Jayesh's schedule → then team wonders why dates slip
- Jayesh suggested (self-initiated!): Romeo should discuss changes w/ Mark + Alan FIRST, only bring finalized requirements to Jayesh
- 🎯 **DECISION: Adjust workflow — leadership discusses changes → consensus → then requirements to Jayesh**
- Mark to have that conversation with Romeo tonight

### 6. 📊 Bundle File Update — Consolidation
- Jayesh consolidating plan + bundle info into ONE file (not separate) — continues Aug 19 direction
- Adding descriptive comments + example rows to help team understand format
- Version 12 to be shared w/ Alan for review; Alan will populate ~10% sample data to validate structure
- Jayesh to WhatsApp when file ready
