## Topics Discussed

### 1. 📦 Bundle UI Presentation — 🔄 SIMPLIFICATION
- Jayesh presented 3 variations for bundle designs (e.g., AT&T wireless + Mint internet → suggest Mint mobile switch, 20% bundle discount)
- **Feedback:** Romeo + Alan both concerned — **"too much information"**, not consumer-friendly
- **Decision:** revert to the cleaner earlier UI Jayesh built (badge with "save more with bundle")
- **Complex calculations + logic stay behind the scenes** — user only sees clean summary of savings

### 2. 🎯 Anchoring Strategy for Bundles (V1 lock)
- **Problem:** too many permutations if all wireless×internet combos surfaced
- **Solution:** **anchor on the user's CURRENT selected mobile + internet carrier**
  - If user has **Mint internet** → show all bundles AROUND Mint
  - If user has **AT&T wireless** → show all bundles AROUND AT&T
  - **Holes are OK** — some combos won't be shown; V1 accepts sub-optimal in exchange for manageable UI
- Rationale: users are familiar with their existing carriers (Xfinity, etc.) — easier to sell "buy one more product from a brand you know" than switch two services

### 3. 🎯 Market Positioning (Romeo's price map)
- **Value brands (Mint, Visible)** = cheapest
- **Cable companies (Xfinity, Spectrum, Cox, Optimum)** = middle
- **Big three (AT&T, Verizon, T-Mobile)** = most expensive
- Strategy: get customer to add **one product** from an existing carrier they already know

### 4. 🎯 Bundle Suggestion Methodology
- **Compare TWO bundles** for each user:
  - Bundle A: switch wireless to broadband provider (anchor internet)
  - Bundle B: switch broadband to wireless provider (anchor mobile)
- **Surface whichever bundle saves more**
- Show best available bundle regardless of provider origin

### 5. 📦 Bundle UI Placement — Separate Screen
- **Do NOT clutter** existing "Maximum Savings" UI with bundle math
- **Keep current maximum savings + current provider displays intact**
- **Add a banner or button** — "Explore bundle opportunities" → clicks through to separate screen
- Everything stays **above the fold** on main results page

### 6. 🎯 12-Month Prepaid Prioritized for Savings Calc
- 6 wireless pricing options: pay-as-you-go, 3-month, 6-month, 12-month prepaid
- **12-month upfront** is cheapest — use as default savings baseline

### 7. ✅ Membership Functionality COMPLETE (web)
- Subscription + one-time "switch pass" purchase both done
- Testing in progress
- **Goes live TOMORROW (Sep 1)**

### 8. 🎯 Port-Out PIN Expiration Management
- **Problem:** PIN expiration varies by provider — 72 hrs / 7 days / 15 days (Google Fi)
- **Solution:** backend admin panel where team enters per-provider expiration deadlines
- Front-end reflects deadline automatically
- **Use case:** user pays $9.99, doesn't act until day 8, PIN expired → prompt them to generate a new PIN (if same phone number)

### 9. ✅ Development Slate — Live TOMORROW (Sep 1)
