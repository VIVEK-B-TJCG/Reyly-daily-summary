### 2. 🐛 User Feedback — Steuart's Case
- **Location bug:** system placed user in **Chicago** incorrectly

- **Romeo's concern:** when estimates are far off, users lose trust in the whole platform

### 3. 🎯 Strategy Decision — Hold, Don't Pivot on Isolated Feedback
- Debate: change system now vs wait for more data at scale
- **Decision:** **DEFER system change** — don't pivot the whole flow on a single user's feedback
- Instead: **make manual update more visible** so users who see wrong values can self-correct
- "TurboTax-style" tweak-your-inputs approach discussed

### 4. 🎯 "Update Your Details" — Prominence Upgrade
- **Decision:** Jayesh adds prominent **link / popup on results page** — "Update your details"
- Placed on main savings/results page so users who see incorrect pre-filled info can fix it in-flow
- No workflow rewrite — just better visibility of existing functionality

### 5. 📦 Bundle Card — New UI Design 🎯
- **Old:** wireless + internet = separate tiles
- **New (Jayesh's proposal):** merged into **single "bundle" card**
- **Presentation logic:**
  - **Default = bundle** IF it saves more than standalone plans
  - **Standalone options remain available** for users who prefer them
- **Neutral comparison across providers** (e.g. Mint bundle vs Xfinity bundle) — platform stays monetization-focused, not provider-locked

### 6. 📊 Bundle DB Structure — Spreadsheet Mapping Approach ⭐
- **Complexity insight:** trying to calculate every provider permutation = too complex
- **Decision:** **secondary mapping table** (spreadsheet-based, NOT DB merge attempt)
- Focus on:
  - **Flat savings** OR **percentage-based savings** per combination
  - Around **~20 entries** target (manageable record count)
- **Multi-month contract handling** (3/6/12 months):
  - Romeo: use multiple columns for different discount periods
  - Alan + Jayesh: refine spreadsheet structure to keep records tight

### 7. 🎯 Bundle Eligibility Tracking
- Some providers only offer bundle discount **IF user already has** existing internet OR wireless service
- **Jayesh to build Excel sheet** mapping:
  - Which combinations exist
  - Bundle terms per provider
  - Cases where one service is **free/discounted** within bundle (e.g. Verizon+Visible)
- **Alan populates** once structure is defined

### 8. Meta Reminder — Scale Feedback First
- Mark + team explicitly aligned: **don't over-index on isolated user reports**
- Wait for **broader data at scale** before pivoting the flow
